# 📊 Sales Performance Dashboard

An interactive **Sales Performance Dashboard** built using **Python, SQL, Pandas, Plotly, and Streamlit** to analyze sales data and uncover valuable business insights. The dashboard enables users to monitor key performance indicators (KPIs), explore sales trends, evaluate regional performance, and identify profitable products through interactive visualizations.

---

## 🚀 Features

- 📈 Interactive dashboard with real-time visualizations
- 💰 Revenue and profit analysis
- 🌍 Region-wise sales performance analysis
- 📦 Category and product-level performance insights
- 📊 Key Performance Indicators (KPIs)
- 🔍 Interactive filters for dynamic data exploration
- 📅 Sales trend analysis over time

---

## 🛠️ Tech Stack

- **Programming Language:** Python
- **Data Processing:** Pandas, NumPy
- **Database:** SQL (SQLite)
- **Visualization:** Plotly
- **Dashboard:** Streamlit

---

## 📁 Dataset

The project uses a retail sales dataset containing information such as:

- Order Date
- Sales
- Profit
- Category
- Sub-Category
- Region
- Customer Segment
- Quantity

The dataset is processed using Python and SQL before being visualized in the dashboard.

## ▶️ Installation & Usage

### 1. Clone the repository

```bash
git clone https://github.com/vedantrane001/Sales-Performance-Dashboard.git
```

### 2. Navigate to the project directory

```bash
cd Sales-Performance-Dashboard
```

### 3. Install the required dependencies

```bash
pip install -r requirements.txt
```

### 4. Run the Streamlit application

```bash
streamlit run app.py
```
